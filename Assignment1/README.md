# Assignment 1 — Code

## Requirements

- Python 3.9+
- Packages: `numpy`, `pandas`, `scipy`, `matplotlib`, `statsmodels`

Install with:
```
pip install numpy pandas scipy matplotlib statsmodels
```

## Running

Each script is standalone; run them individually (order does not matter):

```
python3 problem1.py
python3 problem2.py
python3 problem3.py
python3 problem4.py
python3 problem5.py
```

Each script prints its numeric results to the console and saves its figure(s)
as `.png` files in the same folder (e.g. `problem1_plots.png`).
